🗄️ Как работает база данных и синхронизация с Добро.рф

Короткий ответ: база данных будет собственная, но часть данных (подтверждённые часы) может синхронизироваться с Добро.рф через API. Это не «или-или», а гибридная модель: официальное подтверждение + гибкая система мотивации.

❓ Почему не взять всё с Добро.рф?

Платформа ДОБРО.РФ даёт возможность партнёрам интегрировать сторонние продукты с помощью API — об этом прямо говорит директор по продукту платформы. Но есть важные ограничения:

  • Часы в ЛЭКВ вносятся только зарегистрированными организаторами — если организатор не создавал мероприятие в ЕИС, часы не попадут в электронную книжку.
  • Перенос часов из бумажной книжки возможен только через интеграцию информационной системы организатора с Добро.рф.
  • API даёт доступ к официальным данным, но не заменяет локальную логику: ачивки, уровни, наклейки, лидерборды — это твоя система мотивации, и её нужно хранить у себя.

🔄 Как работает синхронизация с Добро.рф

1
Волонтёр регистрируется в вашей системе и указывает свой ID на Добро.рф (или привязывает через OAuth).
2
Backend периодически (раз в сутки или по запросу) обращается к API Добро.рф и запрашивает подтверждённые часы.
3
Полученные часы записываются в hours_log с пометкой source = 'dobro'.
4
Локальные часы (с мероприятий АНО «АВЮУ», которые не на Добро.рф) записываются с source = 'local'.
5
При начислении ачивок и уровней система суммирует оба источника.
6
В sync_log фиксируется, когда и сколько часов подтянулось — для отладки и прозрачности.

🔗 Как работает интеграция с Добро.рф

Добро.рф уже имеет опыт синхронизации с внешними платформами — например, с Ecowiki.ru. Механизм такой: организатор в личном кабинете включает синхронизацию, после сдачи отчёта часы автоматически появляются в ЛЭКВ.

Для АНО «АВЮУ» это означает:

  • Организатор регистрируется на Добро.рф как организатор волонтёрской деятельности.
  • Мероприятия создаются в ЕИС — тогда часы автоматически попадают в ЛЭКВ.
  • Ваша система через API забирает эти часы и использует их для начисления ачивок и уровней.
  • Если какое-то мероприятие не создано на Добро.рф — часы всё равно можно зачесть локально (через QR-отметку), но они не попадут в официальную книжку.

💡 Что это даёт проекту

  • Волонтёру — единую историю: и в официальной книжке, и в системе мотивации.
  • Организатору — автоматический учёт часов и аналитику вовлечённости.
  • Партнёрам — доступ к лояльной аудитории через программу наград.
  • Вузу — кейс внедрения IT-решения в реальный некоммерческий проект.
